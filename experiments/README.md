# Experiment Lab

Use a reproducible format: hypothesis, method, controlled inputs, environment/provider versions, result, limitations, and conclusion. Prefer provider-neutral concepts and synthetic/public-safe data.

Record unsuccessful and contradictory results. Separate observations from interpretation. Do not fabricate runs, benchmarks, screenshots, citations, or statistical significance. Document cost, external data sharing, and randomness controls where applicable.


## Run your first comparison

Use [the experiment worksheet](WORKSHEET.md) with the [evidence prompt exercise](../prompt-lab/evidence-check.md). Define expected labels before running anything. There are no published community experiment results yet. Submit an original, reproducible report through a focused documentation PR; actual results must be distinguishable from planned checks.
