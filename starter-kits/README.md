# Starter kits

Choose the kit that fits your challenge. Copy it into your own solution repository; preserve licensing and credit. No package downloads, API keys or paid services are required.

| Kit | Start | Verify | Fits |
|---|---|---|---|
| [Python](python/README.md) | Python 3.12+; local CLI | Standard-library unittest | CLI, JSON, search, validation |
| [JavaScript](javascript/README.md) | Node.js 22+; ES modules | Node built-in test runner | Pure data logic and tooling |
| [Web](web/README.md) | Browser; plain HTML/CSS/JS | Manual accessibility checks | Forms, timer, dashboards |

Each challenge links to its own incomplete domain starter, synthetic fixture and validation guide. The kits demonstrate plumbing; they do not implement challenge acceptance criteria. A08 uses a local design worksheet instead of a runtime.

Before expanding a kit, declare any file storage, network, listeners or dependencies. Never put provider credentials in browser code. See [Contributing](../CONTRIBUTING.md).
