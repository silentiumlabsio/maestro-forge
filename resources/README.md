# Resource Vault

The Vault contains reviewed, annotated learning material: original student notes, cheat sheets, a Git/GitHub Learning Center, code patterns, a Secure Coding Cookbook, architecture guidance, build journals, and project-planning templates.

Every external resource needs a short annotation explaining its value. Restricted course material, exams, answer keys, copied textbook pages, pirated resources, and prohibited graded solutions are not accepted.
