# Resource Vault

The Vault contains reviewed, annotated learning material: original student notes, cheat sheets, a Git/GitHub Learning Center, code patterns, a Secure Coding Cookbook, architecture guidance, build journals, and project-planning templates.

Every external resource needs a short annotation explaining its value. Restricted course material, exams, answer keys, copied textbook pages, pirated resources, and prohibited graded solutions are not accepted.

- [Git & GitHub Learning Center](github-learning-center.md)
- [Secure Coding Cookbook](secure-coding-cookbook.md)
- [Cheat Sheets](cheat-sheets.md)
- [Architecture Gallery and Build Journals](architecture-gallery.md)


## Learn by doing

- [Validation and testing](validation-and-testing.md): turn a brief into useful checks.
- [Code patterns](../patterns/README.md): small examples with assumptions and limits.
- [First PR Sandbox](../first-pr-sandbox/README.md): full browser-only contribution rehearsal.
- [Submission evidence](../templates/SUBMISSION_EVIDENCE.md): report checks without overstating results.

Start with the resource needed for your current challenge. Prefer original notes and primary documentation linked by topic; never rehost restricted materials. Suggest an addition with its license, source, intended learner, concrete use and limitations.
