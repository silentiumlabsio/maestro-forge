# Documentation practice card

## Goal
Explain the specific browser task in one sentence.

## Three steps
1. Describe the first action and what the learner should see.
2. Describe the next action and how to check it.
3. Describe the final action and how to confirm the base repository.

## Review question
Ask one focused question about these instructions.
