# Exercise: make a step usable

The following is an intentionally vague teaching example, not a student submission:

> Change the thing, save it, then submit it.

In your own practice card, rewrite this as three clear browser steps for editing a Markdown file on a practice branch and opening a PR. Identify where the learner checks the branch, previews the edit and verifies the base repository.

Add one question a reviewer should answer and a short reflection after review. Use only original text. Do not claim somebody reviewed or merged your work until it actually happened.

Success means another learner can follow the steps without guessing what “thing” or “submit” means. There is no single answer key.
