# Sandbox troubleshooting

| Symptom | Next step |
|---|---|
| No changes to compare | Confirm the edit was committed to the practice branch, not the base. |
| PR targets upstream by accident | Close the mistaken PR with a brief explanation; create the comparison into your fork. |
| Review asks for edits | Commit corrections on the same head branch; refresh the PR. |
| Cannot approve own PR | Self-check for rehearsal; independent approval needs another person. |
| Merge blocked | Read the failing check and review request; only maintainers can resolve repository-policy exceptions. |
| Conflict in shared file | Put your exercise in your own unique practice card. Preserve other authors' work. |
| Fork behind upstream | Sync your fork before starting a new branch; avoid resetting a branch with your own unmerged work. |
| Accidentally exposed a secret | Stop; follow the security policy privately, revoke it and notify the maintainer. Deleting a line is insufficient. |

Never paste private data into a help issue. Include only the public file path, expected action and sanitized error text.
