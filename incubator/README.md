# Project Incubator

The Incubator supports project proposals, the Idea Marketplace, Find a Builder, Review Exchange, open roles, community requests, and one recurring Community Project.

Project states are `idea`, `recruiting`, `building`, `review`, `shipped`, and `archived`. Source stays in a contributor-owned repository unless maintainers explicitly approve a focused core contribution.

Use GitHub issue forms to propose a project or idea, opt in to the builder directory, or request review. Do not publish fake teams, activity, roles, or progress. Community Project code follows the same zero-trust contribution boundary as every other submission.
