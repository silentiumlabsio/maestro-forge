# Forge Handbook

The single starting point for new community members:

1. Browse the [24 official challenges](../challenges/) or [five learning paths](../learning-paths/).
2. Learn the contribution loop in the [Git & GitHub Learning Center](../resources/github-learning-center.md).
3. Read [Contributing](../CONTRIBUTING.md), [Security](../SECURITY.md), and the [AI Assistance Policy](../AI_ASSISTANCE_POLICY.md).
4. Practice a documentation-only contribution in the [First PR Sandbox](../first-pr-sandbox/).
5. Ask a public-safe question through the [Help Center](HELP_CENTER.md).

Executable challenge solutions and community applications remain in contributor-owned repositories. Open pull requests and external links remain untrusted until reviewed.
