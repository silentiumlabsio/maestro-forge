# Interactive learning

Open the site's Challenges catalog and select a challenge. The workspace contains the acceptance checklist from its brief, editable synthetic JSON, a structure check, planning notes and an evidence export. A structure check only checks the example's top-level shape and fields; it does not run your implementation or validate every domain rule. Use the challenge validation guide and your own local tests for correctness.

The Learn page summarizes self-checked criteria. Community offers local worksheets for prompts, experiments, failures and project planning. Record actual observations separately from predictions. No worksheet automatically contacts an AI provider or publishes a submission.

## First PR rehearsal

Open **First PR Sandbox** through Community or search. The interactive rehearsal walks through a practice fork, branch, text edit, preview, commit snapshot, target selection, simulated review and merge. Wrong target choices and incomplete instructions get actionable feedback. Revisions return to editing and require a new snapshot and review. The resulting practice record can be downloaded.

This is a local simulation. For real GitHub practice, follow the linked browser walkthrough in your own fork. Real upstream pull requests still require maintainer review and repository checks. Neither a simulated merge nor a checked checklist grants verification.

## Keep your work

Notes save in your browser. Download an evidence document for a single workspace or use **Back up and restore learning notes** for a JSON backup across workspaces. A restore validates the file and asks before replacing existing notes. Rehearsal records export separately as Markdown.

If saving is blocked, storage is unreadable, or another tab has changed the same workspace, export current notes before reloading. Closing a private browsing window or clearing site data may remove progress. Avoid editing the same workspace in multiple tabs. On a shared computer, export what you need and clear your workspace/site storage when finished.

Never enter real credentials, private student records or restricted course content. Read [Privacy](../PRIVACY.md) and [the submission guide](SUBMITTING.md) before sharing exported evidence.
