# Help Center

Use the **Help Center question** issue form for public, non-sensitive questions about challenges, Git/GitHub, contribution paths, projects, reviews, resources, or Forge Passport.

Before posting, search existing issues and the Forge Handbook. Remove credentials, private repository details, personal/student information, restricted course material, and sensitive vulnerability details.

Security vulnerabilities belong in GitHub private vulnerability reporting, not a help issue. Maintainers and community helpers should answer constructively, avoid requesting unnecessary personal information, and link to reviewed Forge documentation where possible.
