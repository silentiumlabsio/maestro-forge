# Code Patterns

Small, reviewed engineering patterns such as validation, bounded retries, safe error handling, environment variables, redacted logging, pagination, testing, parameterized queries, and safe file handling.

Each pattern should state its context, code, tests, security considerations, limitations, alternatives, language/runtime version, and license. Keep dependencies minimal and never present a snippet as universally safe.


## Read a concrete pattern

- [Pure validation boundaries](validation-and-boundaries.md): ranges, types and test cases.
- [Safe browser rendering](safe-rendering.md): text and URL boundaries.
- [Confined local files](local-files.md): traversal, symlinks and limitations.

Use these as small design lessons, not challenge solutions. Propose another pattern with original code, tests, assumptions and alternatives.
