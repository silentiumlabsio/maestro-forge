# Release Checklist

- [ ] Acceptance criteria and documented tests pass
- [ ] Security and privacy declarations match behavior
- [ ] Dependencies are necessary, locked, reviewed, and attributed
- [ ] No secrets, private data, local paths, or debug settings are included
- [ ] Accessibility and responsive behavior are checked
- [ ] External links and screenshots are reviewed
- [ ] Release notes identify the exact source commit
- [ ] Checksums are generated for distributed artifacts
- [ ] SBOM or provenance is included when appropriate
- [ ] Rollback, quarantine, and revocation paths are understood
