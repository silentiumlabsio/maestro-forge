# Templates

Copy a template into your own repository and fill it with truthful project-specific information. Blank fields and example records are not evidence of completed work.

| Need | Template |
|---|---|
| Prepare challenge review | [Submission evidence](SUBMISSION_EVIDENCE.md) |
| Record decisions while building | [Build journal](build-journal.md) |
| Scope a project | [Project plan](project-planning/PROJECT_PLAN.md) |
| Explain boundaries | [Architecture](project-planning/ARCHITECTURE.md) |
| Compare alternatives | [ADR](project-planning/ADR_TEMPLATE.md) |
| Define validation | [Test plan](project-planning/TEST_PLAN.md) |
| Assess release risk | [Security checklist](project-planning/SECURITY_CHECKLIST.md) |
| Prepare release | [Release checklist](project-planning/RELEASE_CHECKLIST.md) |
| Reflect | [Retrospective](project-planning/RETROSPECTIVE.md) |
| Prepare a personal evidence record | [Forge Passport](FORGE_PASSPORT.md) |

Keep future work labeled planned. Publish only original, public-safe content. See [academic integrity](../ACADEMIC_INTEGRITY.md).

For feedback use [Review feedback](REVIEW_FEEDBACK.md). For real, consented observations use [Usability session](USABILITY_SESSION.md); never fill it with fictional participants.
