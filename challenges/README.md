# Challenge System

Challenges are created and curated by Silentium Labs with room for community proposals.

## Tracks

- [Beginner](beginner/README.md)
- [Intermediate](intermediate/README.md)
- [Advanced](advanced/README.md)

Students may solve the same challenge in different languages unless the brief requires a specific environment. A challenge is a learning brief, not a single official solution.

## Difficulty philosophy

**Beginner** challenges emphasize fundamentals, clear requirements, and a small attack surface.
**Intermediate** challenges introduce persistence, APIs, testing, or richer state.
**Advanced** challenges emphasize architecture, AI reliability, security design, privacy, evaluation, and maintainability.
