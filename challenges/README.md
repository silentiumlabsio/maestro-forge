# Challenge catalog

24 independent practice builds by Silentium Labs: eight per track. Choose a small project, build it in your own repository, then request review with exact-commit evidence. These are community exercises, not official Maestro coursework or answer keys.

New to GitHub? Start with the [First PR Sandbox](../first-pr-sandbox/README.md). Need a sequence? Choose a [learning path](../learning-paths/README.md). Use [starter kits](../starter-kits/README.md) and the [submission guide](../handbook/SUBMITTING.md).

| Track | Entry skills | Suggested scope |
|---|---|---|
| [Beginner](beginner/README.md) | Variables, functions; or basic HTML | One local feature, a few checks |
| [Intermediate](intermediate/README.md) | Tests, validation and simple persistence | Multiple components and failure handling |
| [Advanced](advanced/README.md) | Independent design and risk analysis | Architecture, evaluation and tradeoffs |

Each start package includes an unfinished interface or design worksheet, synthetic input and concrete validation guidance. No full solutions are shipped. Choose your own implementation language where practical; document deviations from the brief. Multiple students can solve the same challenge.

A working artifact does not automatically become Skill Verified. Read the [rubric](../SKILL_VERIFICATION.md), [AI policy](../AI_ASSISTANCE_POLICY.md), [academic integrity rules](../ACADEMIC_INTEGRITY.md) and [untrusted-code boundary](../UNTRUSTED_CODE_POLICY.md).
