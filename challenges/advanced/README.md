# Advanced Challenges

- **[A01 — Local RAG Study Assistant](a01-local-rag-study-assistant/challenge.md)** — Build a retrieval-augmented study assistant over user-provided notes with source citations.
- **[A02 — Offline-First Course Dashboard](a02-offline-first-course-dashboard/challenge.md)** — Design a modular course dashboard that remains useful offline and syncs only when explicitly configured.
- **[A03 — Static Contribution Risk Linter](a03-static-contribution-risk-linter/challenge.md)** — Create a static linter that flags risky patterns in submitted source without executing it.
- **[A04 — Evidence-Aware Study Agent](a04-evidence-aware-study-agent/challenge.md)** — Build an assistant that separates retrieved evidence, model inference, and uncertainty in its answers.
- **[A05 — Challenge Catalog Compiler](a05-challenge-catalog-compiler/challenge.md)** — Build a schema-driven compiler that validates challenge manifests and generates indexes/pages.
- **[A06 — Learning Telemetry Dashboard](a06-learning-telemetry-dashboard/challenge.md)** — Design privacy-conscious local telemetry for study sessions and visualize trends.
- **[A07 — Contribution Reputation Engine](a07-contribution-reputation-engine/challenge.md)** — Create a transparent contribution scoring prototype using merged GitHub activity without turning it into a popularity contest.
- **[A08 — Sandbox Design Challenge](a08-sandbox-design-challenge/challenge.md)** — Design and prototype a safe evaluation architecture for untrusted student code without executing submissions on maintainer infrastructure.
