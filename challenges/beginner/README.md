# Beginner Challenges

- **[B01 — Focus Timer CLI](b01-focus-timer-cli/challenge.md)** — Build a command-line focus timer with configurable work and break periods.
- **[B02 — Flashcard Deck CLI](b02-flashcard-deck-cli/challenge.md)** — Create a local flashcard tool that loads a small deck and quizzes the learner.
- **[B03 — Pomodoro Web App](b03-pomodoro-web-app/challenge.md)** — Build an accessible browser-based Pomodoro timer using plain web technologies.
- **[B04 — Grade Scenario Calculator](b04-grade-scenario-calculator/challenge.md)** — Create a calculator that helps a student estimate course outcomes from weighted categories.
- **[B05 — Study Streak Tracker](b05-study-streak-tracker/challenge.md)** — Build a local study streak tracker that records completed study days.
- **[B06 — Markdown Notes Indexer](b06-markdown-notes-indexer/challenge.md)** — Scan a notes folder and create a simple index of Markdown titles.
- **[B07 — Secret-Safe Config Demo](b07-secret-safe-config-demo/challenge.md)** — Build a tiny app that reads configuration from environment variables without hardcoded secrets.
- **[B08 — Project README Builder](b08-project-readme-builder/challenge.md)** — Create a small tool that asks project questions and generates a clean README draft.
