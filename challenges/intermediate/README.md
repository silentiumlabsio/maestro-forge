# Intermediate challenges

[All tracks](../README.md) · [Starter kits](../../starter-kits/README.md) · [How to submit](../../handbook/SUBMITTING.md)

Bring a working understanding of tests, validation and local state. Keep offline fixtures available when an exercise includes an API.

| Build | Goal |
|---|---|
| [I01 — Adaptive Quiz Engine](i01-adaptive-quiz-engine/README.md) | Build a quiz engine that changes question order or repetition based on previous answers. |
| [I02 — AI Quiz Generator](i02-ai-quiz-generator/README.md) | Create an optional-LLM quiz generator with a clean provider boundary and a deterministic offline mode. |
| [I03 — Repository Activity Dashboard](i03-repository-activity-dashboard/README.md) | Build a dashboard using public GitHub API data for stars, issues, and recent activity. |
| [I04 — Constraint Study Planner](i04-constraint-study-planner/README.md) | Generate a weekly study plan from available time, priorities, and deadlines. |
| [I05 — Offline Flashcard PWA](i05-offline-flashcard-pwa/README.md) | Create an installable flashcard web app that works offline. |
| [I06 — Local Notes Search](i06-local-notes-search/README.md) | Build local full-text or TF-IDF search over a notes directory. |
| [I07 — Secure Starter App](i07-secure-starter-app/README.md) | Create a small web/API starter with input validation, tests, and documented security defaults. |
| [I08 — Challenge Progress Board](i08-challenge-progress-board/README.md) | Build a static dashboard that reads challenge metadata and shows status, owner, and completion progress. |

Every folder has a start guide, an unfinished starter, synthetic input and validation cases. Record actual results; never present the scaffold or example data as a finished student submission.
