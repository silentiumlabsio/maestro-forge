# Intermediate Challenges

- **[I01 — Adaptive Quiz Engine](i01-adaptive-quiz-engine/challenge.md)** — Build a quiz engine that changes question order or repetition based on previous answers.
- **[I02 — AI Quiz Generator](i02-ai-quiz-generator/challenge.md)** — Create an optional-LLM quiz generator with a clean provider boundary and a deterministic offline mode.
- **[I03 — Repository Activity Dashboard](i03-repository-activity-dashboard/challenge.md)** — Build a dashboard using public GitHub API data for stars, issues, and recent activity.
- **[I04 — Constraint Study Planner](i04-constraint-study-planner/challenge.md)** — Generate a weekly study plan from available time, priorities, and deadlines.
- **[I05 — Offline Flashcard PWA](i05-offline-flashcard-pwa/challenge.md)** — Create an installable flashcard web app that works offline.
- **[I06 — Local Notes Search](i06-local-notes-search/challenge.md)** — Build local full-text or TF-IDF search over a notes directory.
- **[I07 — Secure Starter App](i07-secure-starter-app/challenge.md)** — Create a small web/API starter with input validation, tests, and documented security defaults.
- **[I08 — Challenge Progress Board](i08-challenge-progress-board/challenge.md)** — Build a static dashboard that reads challenge metadata and shows status, owner, and completion progress.
