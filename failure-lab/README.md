# Failure Lab

Document the intended outcome, attempted approach, reproducible evidence, observed failure, likely causes, what changed, and what was learned. This is a blameless learning archive, not a ranking or shaming surface.

Remove secrets, private student data, restricted course content, and sensitive exploit details. Credit collaborators and distinguish a hypothesis from a confirmed cause.


## Start with a real failure

Use [the writeup worksheet](WRITEUP.md). Useful topics include a timer that duplicates intervals, a stale cache, a malformed JSON import or an unsupported AI citation. These are suggested topics, not claimed incidents. No community postmortems are published yet. Bring actual sanitized evidence and a specific lesson in a documentation PR.
