# Privacy

## Local learning workspaces

Challenge checklists, drafts, practice inputs and learning notes are saved in browser local storage on this site's origin. The First PR rehearsal saves a separate local practice record. These features do not upload your text or execute it. Shared-device users should export needed work and clear the workspace or site storage before leaving. Browser clearing, private browsing and storage limits can remove progress; download backups regularly.

Notes backups are user-initiated downloads. Restore reads a user-selected JSON file, validates its format and asks before replacing saved learning notes. Sandbox rehearsal records export separately as Markdown. Exported files contain your entered text; keep them private when appropriate. GitHub issue forms and repository links are external services with their own privacy policies. Local progress is self-reported, not reviewed evidence or a credential.

Maestro Forge collects no custom account data at launch and adds no invasive analytics. GitHub hosts the repository and community interactions under its own policies.

Use a GitHub handle as the default public identity. Do not require legal names, personal email addresses, phone numbers, addresses, birth dates, student IDs, grades, precise locations, school schedules, or other unnecessary personal information.

Builder profiles are opt-in. Contributors should share only information they are comfortable making public and may request that a published profile be hidden or archived.

Do not submit secrets, private course records, credentials, private repository names, or sensitive screenshots. Before publication, review images for browser tabs, emails, local paths, IP addresses, student information, tokens, and unrelated people.

If privacy-respecting analytics are considered later, document the fields, purpose, retention, and opt-out before collection begins. Do not silently add tracking pixels, session replay, fingerprinting, or cross-site advertising identifiers.
