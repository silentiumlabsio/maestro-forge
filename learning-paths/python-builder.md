# Python Builder

Move from a safe local CLI to search, testing, and architecture-aware tooling.

[All paths](README.md) · [Challenge catalog](../challenges/README.md)

## Before you start

Be comfortable with functions and reading errors. If new to code, begin with a beginner challenge and one passing test.

## Suggested sequence

1. [B01 — Focus Timer CLI](../challenges/beginner/b01-focus-timer-cli/README.md) — Build a command-line focus timer with configurable work and break periods.
2. [B02 — Flashcard Deck CLI](../challenges/beginner/b02-flashcard-deck-cli/README.md) — Create a local flashcard tool that loads a small deck and quizzes the learner.
3. [B05 — Study Streak Tracker](../challenges/beginner/b05-study-streak-tracker/README.md) — Build a local study streak tracker that records completed study days.
4. [B06 — Markdown Notes Indexer](../challenges/beginner/b06-markdown-notes-indexer/README.md) — Scan a notes folder and create a simple index of Markdown titles.
5. [B07 — Secret-Safe Config Demo](../challenges/beginner/b07-secret-safe-config-demo/README.md) — Build a tiny app that reads configuration from environment variables without hardcoded secrets.
6. [B08 — Project README Builder](../challenges/beginner/b08-project-readme-builder/README.md) — Create a small tool that asks project questions and generates a clean README draft.
7. [I01 — Adaptive Quiz Engine](../challenges/intermediate/i01-adaptive-quiz-engine/README.md) — Build a quiz engine that changes question order or repetition based on previous answers.
8. [I06 — Local Notes Search](../challenges/intermediate/i06-local-notes-search/README.md) — Build local full-text or TF-IDF search over a notes directory.
9. [I07 — Secure Starter App](../challenges/intermediate/i07-secure-starter-app/README.md) — Create a small web/API starter with input validation, tests, and documented security defaults.
10. [A03 — Static Contribution Risk Linter](../challenges/advanced/a03-static-contribution-risk-linter/README.md) — Create a static linter that flags risky patterns in submitted source without executing it.
11. [A05 — Challenge Catalog Compiler](../challenges/advanced/a05-challenge-catalog-compiler/README.md) — Build a schema-driven compiler that validates challenge manifests and generates indexes/pages.

## Checkpoints

- Foundation: explain the input contract and show a normal case plus invalid input.
- Applied: demonstrate a failure, a regression check and documented data boundaries.
- Synthesis: compare design alternatives, show reproducible evidence and identify remaining limitations.

Pause or skip ahead based on your needs. Completing a list does not confer certification or automatic verification. Use the [evidence template](../templates/SUBMISSION_EVIDENCE.md) and request focused review after a useful milestone.
