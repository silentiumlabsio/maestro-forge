Learning paths are suggested journeys through stable challenge IDs. They do not gate participation and do not imply course completion or certification.

| Path | Suggested sequence |
|---|---|
| Python Builder | B01 → B02 → B05 → B06 → B07 → B08 → I01 → I06 → I07 → A03 → A05 |
| Web Builder | B03 → B04 → I03 → I05 → I08 → A02 |
| AI Builder | I02 → A01 → A04 |
| Security Builder | B07 → I07 → A03 → A06 → A08 |
| Open Source Builder | B08 → I03 → I08 → A05 → A07 |

The source of truth is [`docs/data/learning-paths.json`](../docs/data/learning-paths.json). A future Forge Passport skill graph may only derive nodes from verified challenge competencies and accepted contribution evidence—not page views, self-claims, popularity, or repository activity volume.
