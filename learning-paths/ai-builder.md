# AI Builder

Develop provider-neutral AI systems that expose evidence, uncertainty, privacy, and failure modes.

[All paths](README.md) · [Challenge catalog](../challenges/README.md)

## Before you start

Be comfortable with structured data and tests. Begin with mock providers; no paid API is necessary.

## Suggested sequence

1. [I02 — AI Quiz Generator](../challenges/intermediate/i02-ai-quiz-generator/README.md) — Create an optional-LLM quiz generator with a clean provider boundary and a deterministic offline mode.
2. [A01 — Local RAG Study Assistant](../challenges/advanced/a01-local-rag-study-assistant/README.md) — Build a retrieval-augmented study assistant over user-provided notes with source citations.
3. [A04 — Evidence-Aware Study Agent](../challenges/advanced/a04-evidence-aware-study-agent/README.md) — Build an assistant that separates retrieved evidence, model inference, and uncertainty in its answers.

## Checkpoints

- Foundation: explain the input contract and show a normal case plus invalid input.
- Applied: demonstrate a failure, a regression check and documented data boundaries.
- Synthesis: compare design alternatives, show reproducible evidence and identify remaining limitations.

Pause or skip ahead based on your needs. Completing a list does not confer certification or automatic verification. Use the [evidence template](../templates/SUBMISSION_EVIDENCE.md) and request focused review after a useful milestone.
