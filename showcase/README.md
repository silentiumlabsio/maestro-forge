# Built in the Forge

Built in the Forge is a curated metadata showcase, not a mirror of arbitrary student applications. Project source remains contributor-owned by default.

Entries display their review/trust state, link safely to the contributor repository, identify the exact reviewed commit, and avoid claims that review guarantees security. Open issues and pull requests are never presented as verified content.

The launch showcase is intentionally empty until a real submission completes review.


## What belongs in a future card

A project name and plain description; contributor-owned source URL; exact reviewed commit; license; declared capabilities; trust state and review date; accessible, sanitized demo evidence; and known limitations. A video or screenshot alone is insufficient.

Start with [the submission guide](../handbook/SUBMITTING.md). Until a real record is accepted, the site shows an invitation to submit. It must not show invented builders, scores, testimonials, activity or project counts.
