# Recurring Community Project

Maestro Forge may run one larger recurring community build with issues scoped across beginner, intermediate, advanced, documentation, design, accessibility, testing, and review tracks.

Selection requires a public problem statement, contributor-owned repository, maintainers, roles, milestones, security/privacy assessment, issue backlog, code of conduct, release plan, and clear non-goals. No project is selected at launch.

Community Project code follows the same zero-trust boundary as any external submission: no privileged execution, no maintainer secrets, no self-hosted runner for unknown code, exact-commit review evidence, and immediate quarantine/revocation capability.
