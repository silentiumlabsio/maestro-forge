# Non-Code Contribution Tracks

## Documentation

Improve original Forge guides, challenge clarity, project documentation, diagrams, and accessible alternative text. Do not copy restricted course content.

## Design

Contribute reviewable source assets, interaction specifications, layout improvements, or truthful screenshots. Do not add third-party logos, proprietary Maestro assets, fake users, metrics, or endorsements.

## Accessibility

Review keyboard flow, semantics, headings, form labels, focus, contrast, zoom, reduced motion, screen-reader announcements, responsive reflow, and media alternatives. Record the method and exact commit reviewed.

## Translation

Translate only original or clearly licensed Forge material. Preserve meaning, code, links, warnings, attribution, and security language. A bilingual reviewer should inspect translated policy or security content before publication. Translation never grants permission to copy proprietary Maestro material.

## Testing and review

Reproduce behavior, inspect edge cases, test documentation steps, or provide code, UI, architecture, security, and privacy feedback. Reviewer recognition is separate from repository permissions.
