# Prompt Lab

Prompt entries must include:

- goal and expected behavior;
- complete prompt text;
- tested model/provider and date when relevant;
- public-safe example input and output;
- evaluation method;
- limitations and known failure cases;
- safety, privacy, cost, and data-sharing notes;
- version and authorship credit.

Prefer provider-neutral lessons. Popularity is not evidence of quality. Never include credentials, private student data, restricted course material, fabricated output, or a prompt designed for unauthorized access or harm.
