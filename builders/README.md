# Builders and Forge Passport

Builder profiles are public opt-in records using GitHub handles by default. Skills, interests, preferred roles, and availability may be shared; legal names, personal contact details, student IDs, grades, and precise locations are not required.

Forge Passport exports begin as portable Markdown and JSON. Skill graphs and achievements derive only from accepted evidence. Verification binds to exact challenge/rubric versions, repository URL, commit SHA, reviewer, date, and score breakdown.

Badges are community recognition—not professional certification, academic credit, or official Maestro accreditation. The launch directory is empty until people explicitly opt in.
