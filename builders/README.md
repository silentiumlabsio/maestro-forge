# Builders and Forge Passport

Builder profiles are public opt-in records using GitHub handles by default. Skills, interests, preferred roles, and availability may be shared; legal names, personal contact details, student IDs, grades, and precise locations are not required.

Forge Passport exports begin as portable Markdown and JSON. Skill graphs and achievements derive only from accepted evidence. Verification binds to exact challenge/rubric versions, repository URL, commit SHA, reviewer, date, and score breakdown.

Badges are community recognition—not professional certification, academic credit, or official Maestro accreditation. The launch directory is empty until people explicitly opt in.


## Opt in or update a profile

Open [a builder profile request](https://github.com/silentiumlabsio/maestro-forge/issues/new?template=builder-profile.yml) using your public handle, interests, a useful role and availability. Self-described interests are not verified skills. Provide evidence URLs only for work you may share.

Maintainers review consent, minimum public data and any linked evidence before publishing metadata. Request edits or removal through the same form referencing your handle; private concerns follow the privacy policy. Never list another person without their consent.

Use [the Passport template](../templates/FORGE_PASSPORT.md) for a personal evidence draft. Automated exports, derived skill graphs and earned achievement records remain future work until real reviewed records exist. No profiles are seeded.
