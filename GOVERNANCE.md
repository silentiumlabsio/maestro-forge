# Governance

Maestro Forge was created by Silentium Labs and is maintained as an independent community project for Maestro students.

## Roles

### Maintainers
Maintain repository security, architecture, release integrity, challenge quality, and community standards.

### Challenge Authors
Create or improve challenge specifications. Authorship is credited in challenge metadata.

### Contributors
Submit solutions, fixes, projects, docs, and improvements through pull requests.

## Decision model

Security-sensitive decisions remain with maintainers. Community input is encouraged for challenge direction, features, and learning tracks.

The repository should never imply official Maestro endorsement without explicit permission.
